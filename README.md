# epicEFI Installer

This is the epicEFI Installer used to deploy TS, the ST DFU, ST-Link and VCP drivers as well as the epicEFI TS Plugin.

# Building

To build the installer you need Inno Setup. 

Download and install Inno Setup, open the .iss file and click "Compile" in the toolbar.
